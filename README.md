# Freqtrade Bot Sandbox

Mein persönliches Testgelände, um algorithmische Handelsstrategien mit Freqtrade zu entwickeln, zu konfigurieren und lokal zu backtesten.

## Worum geht es hier?
Dieses Repository dient mir als Lernumgebung, um den automatisierten Krypto-Handel zu verstehen. Ich teste hier verschiedene Indikatoren, Parameter und Konfigurationen, um zu sehen, wie sich Strategien unter historischen Marktdaten verhalten.

## Struktur
- `config.json`: Meine lokale Bot-Konfiguration (Paare, Zeitzone, Exchange-Settings).
- `user_data/strategies/MyFirstStrategy.py`: Meine selbst geschriebene Handelsstrategie.

## Tech Stack
- **Framework:** Freqtrade (Python)
- **Version Control:** Git & GitHub
- **Environment:** macOS / VS Code

# Freqtrade Bot Sandbox

A personal sandbox environment to develop, configure, and locally backtest algorithmic trading strategies using Freqtrade.

## What is this?
I created this repository as a learning playground to explore automated crypto trading. It helps me test different indicators, parameters, and configurations to see how strategies hold up against historical market data.

## Project Structure
- `config.json`: My local bot configuration (trading pairs, exchange settings, dry-run mode).
- `user_data/strategies/MyFirstStrategy.py`: My custom trading strategy implementation.

## Tech Stack
- **Framework:** Freqtrade (Python)
- **Version Control:** Git & GitHub
- **Environment:** macOS / VS Code
